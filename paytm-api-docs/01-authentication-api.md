## Login

Source: https://developer.paytmmoney.com/docs/api/login/

**Endpoint:** `https://login.paytmmoney.com/merchant-login?apiKey={api_key}&state={state_key}`  

### Description

> The Paytm Money API login flow starts by navigating to the below public Paytm Money API endpoint. https://login.paytmmoney.com/merchant-login?apiKey={api\_key}&state={state\_key} A successful login comes back with a request\_token as a URL query parameter to the redirect URL (Return URL) registered on the developer portal when creating the api\_key.
>
> 1. Navigate to the above Paytm Money API login page with the api\_key
> 2. A successful login comes back with a request\_token to the registered redirect URL / Return URL
> 3. After receiving the request\_token you have to generate access\_token as explained in the Generate Access Token section

### Request Attributes

Content Type: JSON

#### Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `api_key` | string | optional | A Unique key provided for the merchant/fintech company by Paytm Money |
| `state_key` | string | optional | Variable key which merchant/fintech company expects Paytm Money to return with Request Token. This can be string. |

## Logout

Source: https://developer.paytmmoney.com/docs/api/logout/

**Method:** `DELETE`  
**Endpoint:** `https://developer.paytmmoney.com/accounts/v1/logout`  

### Description

> This call invalidates the access\_token and destroys the API session. After this, the user should be sent through a new login flow before further interactions.

### Request Attributes

Content Type: JSON

#### Head

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `x-jwt-token` | string | optional | xxxxxx ( The one retrieved from Generate Access Token Steps ) . Can be accessed using: {access\_token} or {read\_access\_token} or {public\_access\_token} |

### Response Attributes

Content Type: JSON

#### Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `message` | string | optional | Success message |

### Code Samples

#### CURL

```bash
curl --location --request DELETE 'https://developer.paytmmoney.com/accounts/v1/logout' \
--header 'x-jwt-token: {{JWT-TOKEN}}'
```

### Sample Responses

#### SUCCESS

```json
{
    "message": "User logged out successfully"
}
```

### Possible Response Status

| Code | Status | Message |
| --- | --- | --- |
| PM_MERCHANT_AUTH_401669 | FAILURE | Invalid Token |

## User details

Source: https://developer.paytmmoney.com/docs/api/user-details/

**Method:** `GET`  
**Endpoint:** `https://developer.paytmmoney.com/accounts/v1/user/details`  

### Description

> This API helps you to get the logged in users details.

### Request Attributes

Content Type: JSON

#### Head

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `x-jwt-token` | string | optional | xxxxxx ( The one retrieved from Generate Access Token Steps ) . Can be accessed using: {access\_token} or {read\_access\_token} . |

### Response Attributes

Content Type: JSON

#### Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `requestId` | string | optional | A Unique ID generated by the system when the request is made, in order to keep a track of the requests made on the Paytm Money platform |
| `responseId` | string | optional | A Unique ID generated by the system when the response is rendered |
| `code` | string | optional | Success/Error Code generated depending upon the success/failure of the API Request. |
| `message` | string | optional | Success message |
| `displayMessage` | string | optional | Message to be displayed |

### Code Samples

#### CURL

```bash
curl --location --request GET 'https://developer.paytmmoney.com/accounts/v1/user/details' \
--header 'x-jwt-token: {{JWT-TOKEN}}'
```

### Sample Responses

#### SUCCESS

```json
{
    "data": {
        "kycName": "RAVI BECK",
        "userId" : 195329571,
        "activeSegments": [
            "CASH",
            "FO"
        ]
    },
    "meta": {
        "requestId": null,
        "responseId": "F466583B-3EEA-4232-A958-0DEAD20BFC7C",
        "code": "PM_ONB_SC_200",
        "message": "Success",
        "displayMessage": "PM_ONB_SC_200"
```

### Possible Response Status

| Code | Status | Message |
| --- | --- | --- |
| PM_MERCHANT_SC_400602 | FAILURE | apiKey does not exist |
| PM_MERCHANT_SC_400604 | FAILURE | Request Token does not exist |
| PM_MERCHANT_SC_400605 | FAILURE | Merchant Secret is invalid |
| PM_MERCHANT_SC_400606 | FAILURE | Merchant Secret can not be empty |

## Generate Access Token

Source: https://developer.paytmmoney.com/docs/api/generate-access-token/

**Method:** `POST`  
**Endpoint:** `https://developer.paytmmoney.com/accounts/v2/gettoken`  

### Description

> Access Token allows you to transact and **fetch details** from a particular user account.  
> To generate an Access token you have to **pass API Key+Request Token and API secret**. Generated Access token will be valid till midnight 12 for the day.

### Request Attributes

Content Type: JSON

#### Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `api_secret_key` | string | optional | The apiSecret generated during Merchant Onboarding step for the specific merchant |
| `api_key` | string | optional | The apiKey generated during Merchant Onboarding step for the specific merchant |
| `request_token` | string | optional | The requestToken generated in login after successful authentication and authorization. |

### Response Attributes

Content Type: JSON

#### Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `merchant_id` | string | optional | The ID of the merchant from which the user is logging in. |
| `channel_id` | string | optional | The channel\_id generated during the merchant onboarding step for the specific merchant. |
| `api_key` | string | optional | The apiKey generated during Merchant Onboarding step for the specific merchant |
| `access_token` | string | optional | jwtToken Type 1 with specific apiPermissions. |
| `public_access_token` | string | optional | jwtToken Type 2 with specific apiPermissions. |
| `read_access_token` | string | optional | jwtToken Type 2 with specific apiPermissions. |

### Code Samples

#### CURL

```bash
curl --location --request POST 'https://developer.paytmmoney.com/accounts/v2/gettoken' \
--header 'Content-Type: application/json' \
--data-raw '{
    "api_key" : "{{apiKey}}",
    "api_secret_key" : "{{apiSecret}}",
    "request_token" : "{{requestToken}}"
}'
```

### Sample Responses

#### SUCCESS

```json
{
    "merchant_id": "148",
    "channel_id": "API-148",
    "api_key": "4d4d67195cd34610806f1b068c1ed00e",
    "access_token": "xxxxxxx",
    "public_access_token": "xxxxxxx",
    "read_access_token": "xxxxxx"
}
```

### Possible Response Status

| Code | Status | Message |
| --- | --- | --- |
| PM_MERCHANT_AUTH_400607 | FAILURE | Invalid Api Key or Api Secret Key or Request Token |
| PM_MERCHANT_AUTH_401669 | FAILURE | Invalid Token |
| PM_MERCHANT_AUTH_400606 | FAILURE | Invalid Api Key or Api Secret Key |
| PM_MERCHANT_AUTH_400605 | FAILURE | Invalid Request Token |
| PM_MERCHANT_AUTH_403666 | FAILURE | Merchant is not active |
| PM_MERCHANT_AUTH_401302 | FAILURE | 2FA not completed |
| PM_MERCHANT_AUTH_40301 | FAILURE | User Permission not authorized |
| PM_MERCHANT_AUTH_403301 | FAILURE | Permission denied for user |
| PM_MERCHANT_AUTH_401601 | FAILURE | UNAUTHORIZED |
| PM_MERCHANT_AUTH_403304 | FAILURE | User not allowed |
