# Security Master

- [Security master](#security-master)

## Security master

Source: https://developer.paytmmoney.com/docs/api/security-master/

**Method:** `GET`  

### Description

> There are thousands of different kinds of securities or instruments traded across multiple exchanges and segments, Any application that facilitates trading needs to have a master list of these instruments. The Security Master API provides a consolidated, import-ready CSV list of securities/instruments available for trading.
