# Rates Limits

> Source: https://v2api.aliceblueonline.com/Rates%20Limits/

> **Note**
>
> In order to make sure all clients requests are treated equally, Aliceblue has setup certain limits to the number of requests each client can make through API.

## Introduction

The following are the rate limits for API users

1. Orders - **NOT LIMITED**. Placing a new order, Modifying an existing order, square off positions and Cancelling an order are all not limited.
2. All other requests -- **Limited to 1800 requests per 15 minitues**. This limit will be reset every 15 minutes to 1800 again.
