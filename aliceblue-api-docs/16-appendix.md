## Product Type

| Communicating With Rest API | Description |
| --- | --- |
| INTRADAY | Positions are squared off within the same trading day. No delivery of shares occurs, and only margin is required to trade. |
| LONGTERM | Delivery-based product where securities are purchased and held beyond the trading day, with full payment required at the time of purchase. |
| MTF | MTF (Margin Trading Facility) allows clients to buy stocks by paying only a part of the total value (margin) while the broker funds the rest, enabling leveraged delivery-based trading. |
