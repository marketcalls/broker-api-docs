# API Changelog

Changes and upgrades made to the XStream APIs.

> Source: https://xstream.5paisa.com/dev-docs/docFundamentals/api-changelog

## 2024-05-29 — Webhook

- **API:** Tradingview Webhook
- **Added:** Support for NSE Options

As you might know, TradingView has started supporting NSE Options. In line with these changes, our Webhook API now supports NSE Options. This enhancement allows you to:

- **Set Alerts**: Directly set alerts for NSE Options on TradingView.
- **Algorithmic Trading**: Write your own algorithms with Pine Script and execute trades directly in your 5paisa account.

With this update, you can seamlessly integrate your trading strategies and alerts from TradingView to execute trades on NSE Options through your 5paisa account.

## 2023-11-28 — Scrip Master

- **API:** Scrip Master
- **Added:** New ScripMaster API

The [scrip master](https://xstream.5paisa.com/dev-docs/docFundamentals/scrip-master) API is developed to fetch realtime scrip data. The API comes with segment filter which allows you to fetch only intended data.
