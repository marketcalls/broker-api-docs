# WebSocket

Stream real-time price updates and market events for subscribed instruments via WebSocket connectivity.

## Available WebSocket Endpoints

### Market Data Feed V3

Connect to live market data via WebSocket using Upstox API V3, delivering real-time price updates and market events for subscribed instruments.

### Get Market Data Feed Authorized Url V3

Provides the authorized WebSocket endpoint URL required for V3 market data streaming before establishing connections.

### Portfolio Stream Feed

Delivers real-time order and position updates. Receive real-time order and position updates as they occur in your account.

### Get Portfolio Stream Feed Authorized Url

Furnishes the authorized endpoint URL necessary for portfolio stream connections.

### Market Data Feed

The standard market data WebSocket feed for streaming live price information.

### Get Market Data Feed Authorized Url

Provides authorization URLs required to access market data feeds.
