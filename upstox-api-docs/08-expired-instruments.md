# Expired Instruments

The Expired Instruments section provides access to historical futures and options contract data through the Upstox API. This functionality enables developers to retrieve expired instrument details for backtesting, analysis, and trading application development.

## Available Endpoints

### 1. Get Expiries

Retrieve all available expiry dates for an underlying instrument, allowing access to futures and options expiry schedules for F&O trade planning.

### 2. Get Expired Option Contracts

Access historical options data for an underlying instrument, supporting strategy backtesting and analysis through expired options contract retrieval.

### 3. Get Expired Future Contracts

Obtain historical futures data for an underlying instrument, enabling analysis and backtesting of expired future contracts.

### 4. Get Expired Historical Candle Data

Fetch historical OHLC (Open, High, Low, Close) candle data for expired contracts.

**Supported timeframes:**

- 1-minute
- 30-minute
- Daily
- Weekly
- Monthly
