# Trade Profit And Loss

APIs for generating comprehensive P&L reports. Track P&L, trade charges, and metadata across your complete equity and derivatives trade history.

## Endpoints

### Get Report Meta Data

Retrieves profit and loss report metadata including summary statistics, trade counts, and aggregated P&L information for financial reporting purposes.

### Get Profit Loss Report

Provides trade-wise profit and loss data with detailed per-trade breakdowns and associated charge calculations based on executed trades.

### Get Trades Charges

Returns trade charges and fees incurred on executed trades, including brokerage, taxes, and other charge breakdowns organized by trade ID.
