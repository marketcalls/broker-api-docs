# Market Quote

Retrieve real-time market quotes via Upstox API including full quotes, OHLC data, LTP prices, and option Greeks.

## Endpoints

### Full Market Quotes

Obtain comprehensive market snapshots for up to 500 instruments, encompassing OHLC values, trading volume, and bid-ask depth information.

### OHLC Quotes V3

Access open, high, low, and close pricing data for up to 500 instruments using the V3 API version through a single bulk request.

### LTP Quotes V3

Retrieve last traded price information for up to 500 instruments instantaneously through batch requests.

### Option Greeks

Obtain Greek values for options trading, including delta, gamma, theta, vega, and implied volatility metrics for analytical purposes.

### OHLC Quotes

Get OHLC pricing snapshots for equities and derivatives across up to 500 instruments.

### LTP Quotes

Fetch real-time last traded price data for equities and derivatives in consolidated API calls.

## Key Features

- Supports NSE and BSE instruments
- Bulk request capability (up to 500 instruments per call)
- Real-time data delivery
- Dedicated derivatives analysis support through Greek calculations
