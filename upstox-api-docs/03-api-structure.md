# API Structure

The Upstox Developer API documentation provides guidance on API request and response structures for building trading and investment applications.

## Sections

1. **Request Structure** - Details covering HTTP methods, headers, authorization tokens, and payload formatting for REST API calls used in trading applications.

2. **Response Structure** - Explanation of how Upstox formats API responses, including success and error payloads across single objects, lists, and paginated result sets.

3. **Error Codes** - A reference guide documenting HTTP status codes and application-specific error codes with troubleshooting guidance.
