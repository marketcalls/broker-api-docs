# Notifier Webhook Endpoint

## Overview

A notifier webhook endpoint is a designated URL used to receive automated notifications, particularly access tokens after events occur.

## Core Characteristics

- **Function:** Receives system-generated notifications (access tokens)
- **Setup:** Configured during application creation
- **Protocol:** Operates as a POST API
- **Response:** Accepts either plain string or JSON responses
- **Security:** Does not require authentication

## Configuration

1. Navigate to Upstox My Apps dashboard
2. Select "New App" or "Edit" existing
3. Configure the "Notifier Webhook Endpoint" field
4. Complete all fields and click "Continue"
