# Portfolio

Portfolio API endpoints enable developers to access holdings, positions, and conversion features for comprehensive portfolio management.

## Endpoints

### Get Positions

Retrieve current day trading positions with real-time profit/loss calculations, quantity information, and margin requirements for all active positions in a user's portfolio.

### Get MTF Positions

Access Margin Trade Funding (MTF) positions, displaying current MTF holdings alongside quantity metrics, valuation data, and associated margin details.

### Convert Positions

Modify the margin product classification of an open position, enabling transitions between intraday, delivery, and MTF product categories for enhanced portfolio flexibility.

### Get Holdings

Obtain long-term portfolio holdings data, including current valuations, profit/loss metrics, and comprehensive details for stocks maintained across multiple trading sessions.
