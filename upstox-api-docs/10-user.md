# User

The User section provides endpoints for retrieving authenticated user account information, including profile details and financial data.

## Endpoints

### Get Profile

Fetch user profile information using the Upstox API. Retrieve account details, enabled exchanges, order types, and product configurations for integrated applications.

### Get Fund And Margin

Retrieve user fund balance and margin details for equity and commodity segments using the Upstox API. Check available funds and utilized margin.
