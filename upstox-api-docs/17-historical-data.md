# Historical Data

Access candlestick OHLC (Open, High, Low, Close) data across various timeframes for NSE and BSE instruments.

## Endpoints

### Historical Candle Data V3

Fetch historical OHLC candle data with expanded interval options supporting multiple timeframes for technical analysis.

### Intraday Candle Data V3

Provides intraday OHLC candle data with expanded interval options for current trading day analysis.

### Historical Candle Data

Supports 1-minute, 30-minute, daily, weekly, and monthly intervals for charting purposes.

### Intraday Candle Data

Enables retrieval of current trading day price values for real-time charting and trend analysis.
