# SDK

Upstox provides official SDKs to streamline trading app integration by reducing complexity and development time.

## Supported Languages

- Python
- Java
- Node.js
- PHP
- .NET

## Sections

1. **What's an SDK?** - SDK concepts and how Upstox's SDK streamlines trading app integration
2. **Prerequisites** - Setup requirements covering API credentials, development environment configuration, and language-specific steps
3. **Installing the Upstox SDK** - Installation guides for each supported language with step-by-step setup instructions
4. **Build using Sandbox** - Testing guidance for developers to configure and test trading apps using sandbox mode before production deployment
