## HTTP Status Codes

HDFC Sky Open API uses standard HTTP status codes to indicate the success or failure of a request. Here are some common status codes you may encounter:

- **200 OK:** The request was successful.
- **400 Bad Request:** The request was invalid or malformed.
- **401 Unauthorized:** Authentication is required to access the resource.
- **404 Not Found:** The requested resource could not be found.
- **5xx Server Errors:** An error occurred on the server side.
