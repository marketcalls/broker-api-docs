# Changelog

Groww documents these updates under API version `1.0`:

| Date / period | Update |
| --- | --- |
| 2 December 2025 | Added User Profile API. |
| 24 November 2025 | Added Option Chain API. |
| 8 November 2025 | Added `realised_pnl` to positions responses for closed-position P&L tracking across position queries. |
| 3 October 2025 | Added historical market data from 2020, candles from 1-minute to 1-month intervals, derivatives expiries, and contracts APIs. |
| Initial release | Order management for equity and derivatives; smart orders; portfolio positions and holdings; live market data; margin calculations; instrument master/search; access token, API key, and TOTP authentication. |

## Version Policy

Groww describes its versioning as partial semantic versioning (`MAJOR.MINOR`). Deprecated endpoints receive six months' sunset notice.
